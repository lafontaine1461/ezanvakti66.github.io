Ezan Vakti66 — GitHub Pages aktarımı

1. Bu ZIP dosyasını telefonda veya bilgisayarda açın.
2. ZIP içindeki tüm dosya ve klasörleri (index.html, assets/, favicon.svg, ads.txt, app-ads.txt, robots.txt, .nojekyll) GitHub deposunun ana dizinine yükleyin.
3. GitHub'da Settings > Pages bölümünde yayın kaynağının main dalı ve /(root) olduğuna bakın.
4. Commit edip dağıtımın tamamlanmasını bekleyin.

Önemli: ZIP'in kendisini GitHub'a yüklemek siteyi güncellemez; içindekiler ana dizine çıkarılmalıdır.
